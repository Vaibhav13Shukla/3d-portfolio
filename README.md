# 🚀 3D Developer Portfolio — Vaibhav Shukla

A high-performance, personalized 3D developer portfolio built with React, TypeScript, Three.js, React Three Fiber, and GSAP, styled with the **Cobalt Signal** engineering theme.

---

## 🛠️ Features & Tech Stack

### Core
- **Framework & Language**: React 18, TypeScript, Vite
- **Styling & Theme**: Cobalt Signal (Electric Sky Blue `#38BDF8`, Deep Navy `#0B0F19`)
- **3D Engine**: Three.js, `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`
- **Animations**: GSAP + `@gsap/react`, ScrollTrigger, ScrollSmoother
- **Deployment**: Vercel & GitHub Actions

### Highlights
- Responsive 3D character scene with dynamic ambient lighting and physics-based techstack interactions.
- Smooth scroll transitions, customized cursor trail, and clean engineering section layouts.
- Dynamic project carousel showcasing **SRE-Bot**, **Adaptive Soundtrack AI**, and **AI Recruiting Platform**.

---

## 🏃 Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Quick Start
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
